3. Conexión a Base de Datos e Infraestructura

El proyecto utiliza TypeORM sobre una base de datos MySQL.

Observación de Seguridad

Las credenciales de la base de datos están "hardcodeadas" (incrustadas) en el app.module.ts. Deberían migrarse al uso de variables de entorno mediante @nestjs/config (que ya está en package.json).

TypeOrmModule.forRoot({ type: 'mysql', host: '127.0.0.1', port: 3306, username: 'root', password: '***', database: 'databasetoro', entities: [__dirname + '/**/*.entity{.ts,.js}'], synchronize: true, // ¡Peligroso en producción! })
4. Sistema de Autenticación y Seguridad

Basado en las dependencias analizadas, la aplicación implementa:

  • Autenticación: Basada en Tokens JWT (JSON Web Tokens) usando @nestjs/passport, passport-jwt y @nestjs/jwt.
  • Estrategias Passport: Emplea passport-local (probablemente para login con usuario/contraseña) y passport-jwt (para proteger endpoints validando el token en los headers).
  • Encriptación: Uso de bcrypt (v5.1.0) para el hasheo de contraseñas de usuarios.
  • CORS: Habilitado a través de los paquetes estándar, permitiendo la comunicación con el frontend/clientes externos.
